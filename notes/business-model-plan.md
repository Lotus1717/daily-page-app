# 拾页商业模式 & 私域运营规划

> 记录时间：2026-06-09
> 来源：与 tanmy 的讨论

---

## 一、产品定位

**「拾页」** — 不用读完一本书，每天一页就好。读完了，写一句话。

- 内容来源：用户手动添加藏书，服务端生成每日书摘（探索模式可随机荐书）
- 核心价值：每日书摘 + AI 引导提问 + 阅读感想记录
- v1 免费：3 本在读书队列 + 可选加入书友会微信群

---

## 二、付费模式设计（三层）

### 🆓 免费层 — 基础体验

- 每日一页书摘
- AI 引导提问
- 写感想
- 3 本在读书队列
- 基本阅读统计
- 加入书友会微信群（可选，「我」页入口）

### 🌟 拾页 Pro — ¥9.9/月 或 ¥88/年（¥7.3/月）

解锁功能：
- **多本在读书**：3 本 → 10 本
- **AI 深度分析**：每周/月阅读报告（主题关联、观点变化、思考模式）
- **历史回溯**：查看任意日期的书摘和感想（免费版限最近 30 天）
- **多设备同步**：iPhone + iPad + 网页端
- **「我的阅读日记」**：月底 AI 自动整理本月感想为一篇叙事短文（核心付费钩子）

### 🏔️ 拾页 终身（限量）— ¥298

- 所有 Pro 功能永久使用
- 阅读数据导出（Markdown / JSON / PDF）
- 未来新功能优先体验
- 特殊徽章

### 定价逻辑

- ¥9.9/月 在知识付费里属低决策成本档位
- 核心阅读体验不设限，付费解锁的是"深度 + 扩展"功能
- 终身版作为早期支持者锚点，快速回血

## 三、私域运营规划（先做群，为 Pro 铺垫）

### 3.1 App 内群入口

**位置方案（v1 已实现第 1 项）：**
1. ✅ **「我」页面** → 感想记录下方卡片："加入拾页书友会"
2. ⏸️ **写感想后横幅** → v1.1 再做（累计 3–5 条感想后轻提示，可关闭）

**点击后展示：**
- 微信群二维码（需后台配置，过期可更新）
- 钩子文案："每周精选书单｜群友在读排行｜每月共读活动"
- 实时人数："已有 xx 位书友"

**二维码更新机制（已实现方案 1）：**
- `docs/community.json` 配置 `qr_image_url`，GitHub Pages 自动发布
- 二维码图片放 `docs/images/community-qr.png`，群满换图后 push 即可
- 方案 2（备选）：企业微信「加入群聊」永久码

### 3.2 微信群规划

**群名：** 拾页 · 书友会

**后续可扩展的群矩阵：**

| 群类型 | 用途 | 周期 |
|--------|------|------|
| 📖 当期读书群 | 针对一本书/一个计划 | 限时，结束后解散或合并 |
| 🏠 拾页书友会 | 大本营，所有活跃用户 | 长期 |
| 🌟 Pro 内测群 | 付费用户专属 | 长期，高质量 |

### 3.3 群运营 SOP（最小版本）

| 时间 | 运营动作 |
|------|---------|
| **随时** | 往群里扔 App 书摘截图（需 App 支持一键分享图片） |
| **每天** | 抛个阅读话题："今天读到哪句话最有感触？" |
| **每周** | 群友本周在读 Top 5 书单 |
| **每月** | 共读活动 + 最佳感想评选 |

**转化路径（不硬推，用内容种草）：**
1. 免费用户在群里看到别人的 AI 阅读报告 → 想拥有 → 引导 Pro
2. 每月共读需要多本书管理 → 引导 Pro
3. Pro 内测群 → 制造稀缺感，持续种草

## 四、自动化建议（n8n）

阅读计划的功能可以和群联动做自动化，降低人工成本：

```
App 用户打卡 → n8n 触发 → 群内推送打卡消息
群内收集感想 → 每周自动整理 → 生成书单卡片
新用户进群 → 自动欢迎 + 新手攻略
```

---

## 五、实施节奏

| 阶段 | 动作 |
|------|------|
| **本周** | 建群 → App 加群入口 → 自己带群节奏 |
| **短期** | 完善 App 一键分享书摘功能 → 群活跃起来 |
| **中期** | 上线阅读计划功能 → 群内共读活动 |
| **长期** | 拾页 Pro 上线 → 私域转化 |
