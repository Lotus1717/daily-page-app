# 拾页商业模式 & 私域运营规划

> 记录时间：2026-06-09
> 来源：与 tanmy 的讨论

---

## 一、产品定位

**「拾页」** — 不用读完一本书，每天一页就好。读完了，写一句话。

- 内容来源：用户手动添加藏书，服务端生成每日书摘（探索模式可随机荐书）
- 核心价值：每日书摘 + AI 引导提问 + 阅读感想记录
- v1 免费：3 本在读书队列 + 可选关注读书公众号

---

## 二、付费模式设计（三层）

### 🆓 免费层 — 基础体验

- 每日一页书摘
- AI 引导提问
- 写感想
- 3 本在读书队列
- 基本阅读统计
- 关注拾页公众号（可选，「我」页入口）

### 🌟 拾页 Pro — ¥9.9/月 或 ¥88/年（¥7.3/月）

解锁功能：
- **多本在读书**：3 本 → 10 本
- **AI 深度分析**：每周/月阅读报告（主题关联、观点变化、思考模式）
- **历史回溯**：查看任意日期的书摘和感想（免费版限最近 30 天）
- **多设备同步**：iPhone + iPad + 网页端
- **「我的阅读日记」**：月底 AI 自动整理本月感想为一篇叙事短文（核心付费钩子）

### 🏔️ 拾页 终身（限量）— ¥298

- 所有 Pro 功能永久使用
- 阅读数据导出（Markdown / JSON / PDF）
- 未来新功能优先体验
- 特殊徽章

### 定价逻辑

- ¥9.9/月 在知识付费里属低决策成本档位
- 核心阅读体验不设限，付费解锁的是"深度 + 扩展"功能
- 终身版作为早期支持者锚点，快速回血

## 三、私域运营规划（公众号为主，为 Pro 铺垫）

> **2026-06-09 调整：** 微信群改为公众号，减少打扰，以订阅推送为主。

### 3.1 App 内公众号入口

**位置方案（v1 已实现第 1 项）：**
1. ✅ **「我」页面** → 感想记录下方卡片："关注拾页公众号"
2. ⏸️ **写感想后横幅** → v1.1 再做（累计 3–5 条感想后轻提示，可关闭）

**点击后展示：**
- 公众号关注二维码（`docs/community.json` 远程配置）
- 内容预告标签：每日一页推送｜每周精选书单｜每月共读活动

**二维码更新机制（已实现）：**
- `docs/community.json` 配置 `qr_image_url`，GitHub Pages 自动发布
- 二维码图片放 `docs/images/community-qr.png`，换号后 push 即可

### 3.2 公众号定位

**名称建议：** 拾页 · 读书（或拾页读书）

**内容节奏（不打扰原则）：**

| 频率 | 推送内容 |
|------|---------|
| **每天 1 条** | 一页书摘 + 一句感想引导（与 App 今日内容呼应） |
| **每周 1 条** | 精选书单（5 本，附一句话推荐理由） |
| **每月 1 条** | 共读活动预告 / 回顾（报名在推文留言或小程序，非群轰炸） |

**不做：** 群消息轰炸、实时聊天、强提醒。读者自取所需，取关无负担。

### 3.3 公众号运营 SOP（最小版本）

| 时间 | 运营动作 |
|------|---------|
| **每天** | 定时推送：今日书摘 + 「你会写下什么感想？」 |
| **每周** | 周五推送：本周精选书单 |
| **每月** | 月初推送：本月共读书目 + 月末感想精选 |
| **随时** | App 内分享书摘到朋友圈/公众号素材库（待 App 支持分享图） |

**转化路径（内容种草，不硬推）：**
1. 公众号读者看到深度阅读报告示例 → 下载 App
2. 每月共读需要多本书管理 → 引导 Pro（后续）
3. Pro 内测群 → 制造稀缺感，持续种草

## 四、自动化建议（n8n）

阅读计划的功能可以和群联动做自动化，降低人工成本：

```
App 用户打卡 → n8n 触发 → 群内推送打卡消息
群内收集感想 → 每周自动整理 → 生成书单卡片
新用户进群 → 自动欢迎 + 新手攻略
```

## 五、实施节奏

| 阶段 | 动作 |
|------|------|
| **本周** | 建群 → App 加群入口 → 自己带群节奏 |
| **短期** | 完善 App 一键分享书摘功能 → 群活跃起来 |
| **中期** | 上线阅读计划功能 → 群内共读活动 |
| **长期** | 拾页 Pro 上线 → 私域转化 |
